# P1.2 — Grab a free-floating object with hands only

**Phase:** P1 · **Est:** 45 min · **Depends on:** P1.1 · **Workstream:** W2
**Gate fed:** G1

## Why this exists
Grab is the input for the entire core mechanic. It must work on a hand-held object in mid-air, with no ray and no controller.

## Do this
1. Add an ISDK `HandGrabInteractable` to a test cube plus a `HandGrabInteractor` on each hand.
2. Configure grab type to pinch, with a generous pinch threshold for reliability.
3. Disable ray interaction in the scene so nothing can silently fall back.
4. Test: can you grab, move, and release a floating cube with either hand, 20 times, without a miss?
5. Log miss rate. If >2 misses in 20, widen the grab threshold before proceeding.

## Done when
- [ ] 20/20 successful grabs with each hand
- [ ] No ray or controller fallback active
- [ ] Miss rate recorded

## Artefacts produced
- `phases/p1-derisk/grab-log.md` with the 20-trial result

## Traps
- Tuning pinch too tight and blaming it on the tracker
- Leaving ray interaction enabled and not noticing the fallback
