# P1.1 — Custom hand visual running at frame rate

**Phase:** P1 · **Est:** 45 min · **Depends on:** P0.4 · **Workstream:** W2
**Gate fed:** G1

## Why this exists
The stock ISDK hand reads as a demo. Ours is the product's main character — and a custom visual is also the cheapest way to prove we control the tracking pipeline rather than inheriting whatever the sample did.

## Do this
1. Import a low-poly hand mesh with at least 5 fingers and a palm, skinned to 26 joints.
2. Wire `OVRSkeleton` (or the OpenXR hand equivalent under the v207 rig) to drive joint transforms each frame.
3. Assign the mesh to both hands; verify wrist, finger spread and thumb opposition read correctly.
4. Add a confidence readout from the tracker's hand confidence value, visible only in a debug build.
5. Measure: triangle count, draw calls, and frame time with both hands tracked.

## Done when
- [ ] Both hands render and track with no visible lag
- [ ] Joint count and names documented
- [ ] Frame time impact measured, not estimated

## Artefacts produced

## Traps
- Using the stock hand 'for now' — it becomes the product by accident
- Re-skinning 26 joints to a 20-bone rig and silently mangling the fingers
