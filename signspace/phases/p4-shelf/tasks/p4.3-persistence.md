# P4.3 — Persistence across relaunch, reboot and room

**Phase:** P4 · **Est:** 1.5 h · **Depends on:** P4.2 · **Workstream:** W2
**Gate fed:** G4

## Why this exists
If the shelf doesn't survive, the entire retention argument in the submission is false. This is the cheapest feature with the highest claim attached to it.

## Do this
1. Persist: room UUID, anchor GUID, per-shape unlock timestamps, layout variant, and a schema version.
2. On launch: re-resolve the room, then the anchor, then restore objects in unlock order.
3. Handle the three degraded cases explicitly: same room / different room / room not found.
4. Test: kill and relaunch ×5, headset reboot ×1, walk to another room ×1, return ×1.
5. Record the full matrix in `phases/p4-shelf/persistence-matrix.md`.

## Done when
- [ ] Shelf restores in the same room across 5 relaunches and 1 reboot
- [ ] Different-room behaviour is defined and non-destructive
- [ ] Schema version stored

## Artefacts produced
- `unity/Assets/_Project/Scripts/Core/SaveSystem.cs`
- `phases/p4-shelf/persistence-matrix.md`
