## What was built

`Scripts/UI/PassthroughToggle.cs` — `P` in a development build flips the passthrough layer's `hidden`
field, found by name through reflection so the UI assembly does not take a compile dependency on the
XR SDK. It shares a GameObject with `DevOnly`, so a release build removes the key entirely (and
`DevOnly` disables the object before `Start`, so the layer is not touched). The toggle never changes
hands, shelf, anchor or pose: the room is the only variable, which is what makes the pair honest.

If no layer exists, it reports that once and returns `false` rather than pretending to have filmed
something.
