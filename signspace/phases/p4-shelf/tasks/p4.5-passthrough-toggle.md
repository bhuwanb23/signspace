# P4.5 — Passthrough on/off comparison, built for the video

**Phase:** P4 · **Est:** 45 min · **Depends on:** P4.1 · **Workstream:** W4
**Gate fed:** G4

## Why this exists
The rubric asks whether the experience would play the same with passthrough off. We build the comparison rather than arguing it, because a judge can watch it in three seconds.

## Do this
1. Add a debug-only toggle (not shipped in the default build) that flips passthrough.
2. Film: same shot, same hand pose, 3 s with passthrough on, 3 s with it off.
3. The 'off' version must visibly lose the grounding of the shelf and the hands-on-table relationship.
4. Store the two clips in `assets/raw/video/passthrough-{on,off}.mp4` for P9.4.

## Done when
- [ ] Two matched 3 s clips captured
- [ ] The difference is visible without narration

## Artefacts produced
- `assets/raw/video/passthrough-on.mp4`, `passthrough-off.mp4`

## Traps
- Staging the comparison in a way that flatters us dishonestly — the judge must be able to tell it's the same scene
