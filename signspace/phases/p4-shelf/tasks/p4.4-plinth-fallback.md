# P4.4 — The plinth: never show an error, never depend on a surface

**Phase:** P4 · **Est:** 1 h · **Depends on:** P4.1 · **Workstream:** W2
**Gate fed:** G4

## Why this exists
Many judges will test sitting on a sofa, on a bed, or on a plane tray. A product that requires a desk fails the airplane-seat test for reasons that have nothing to do with the idea.

## Do this
1. Build a virtual plinth that reads as a physical object: it has a shadow-catching gradient, a slight tilt, and it sits at the same visual height as a real surface would.
2. Route to it silently when MRUK finds nothing, with no message.
3. If a surface appears mid-session, offer a single quiet affordance to move to it — never auto-migrate.
4. Test in a room with the lights off and nothing detectable.

## Done when
- [ ] Plinth appears instantly when no surface exists
- [ ] No error string, no spinner, no timeout
- [ ] Migration is user-initiated only
