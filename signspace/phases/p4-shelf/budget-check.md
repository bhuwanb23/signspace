## What this does not prove

- Nothing here is a device measurement. Draw calls assume one pass per renderer; triangle counts rely on the declared box constants matching the mesh recipes. Materials are an assumption, not parsed assets. Frame time and idle CPU require a Quest 3S capture (<1% CPU for the breathing, or the idle is dropped).
- Grid dimensions measure slot centres only, not object bounds or visual overlap. Check spacing and rendering in Unity/device.
- Markers are counted for all twelve slots because a filled slot keeps its marker. If P7 drops the markers on filled slots the single-pass estimate drops twelve draw calls.
- Twelve objects at 72 triangles is ~0.9k triangles: the triangles were never the risk. The draw calls and the single Update are.
