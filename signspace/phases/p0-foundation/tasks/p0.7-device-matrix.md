# P0.7 — Lock the device matrix and the test rig

**Phase:** P0 · **Est:** 20 min · **Depends on:** P0.4 · **Workstream:** W5
**Gate fed:** G0

## Why this exists
Judges test on Quest 3 **and** 3S. We build against the weaker device so the strong one is free. Without a named device list, nobody knows what 'it works' means.

## Do this
1. List every physical headset available, with owner and location.
2. Declare the **primary build device** (Quest 3S — the harder target).
3. Declare the **verification device** (Quest 3).
4. Declare the room/lighting conditions that represent the judge's environment (a normal living room at 7 p.m., not a lab).
5. Note whether any device supports eye tracking — if none does, P6 becomes simulator-dependent and that must be known now.

## Done when
- [ ] Both devices named, or the gap explicitly documented
- [ ] Lighting conditions written down
- [ ] Eye-tracking availability known

## Artefacts produced
- `phases/p0-foundation/devices.md`

## Traps
- Only owning a Quest 3 and discovering 3S thermal limits on Day 10
- Testing only in daylight
