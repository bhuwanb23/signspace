# P0.5 — Verify the Invite URL from a clean, signed-out, non-developer account

**Phase:** P0 · **Est:** 30 min · **Depends on:** P0.3 · **Workstream:** W5
**Gate fed:** G0

## Why this exists
Judges are not developers. If the invite flow requires a developer account, a sideload, or any special step, the entry is judged as uninstallable. This is checked on Day 1 and again in P9.7, because it can silently regress.

## Do this
1. Generate the invite URL / release channel link for the app.
2. Open it on a phone or browser in a **private window, signed out of everything Meta**.
3. Follow the flow as a non-developer would: sign in, accept, install to a headset.
4. Record every step of the flow in `phases/p0-foundation/invite-flow.md`, with screenshots.
5. Note the number of taps and any point where a user could fall out.

## Done when
- [ ] A signed-out stranger can reach the install prompt
- [ ] The number of required steps is documented
- [ ] Any blocker (developer mode, sideload) is identified now, not later

## Artefacts produced
- `phases/p0-foundation/invite-flow.md` with screenshots

## Traps
- Testing the URL while signed in as the developer — it always works for you
- Assuming an invite link survives a channel re-upload; re-verify at P9.7
