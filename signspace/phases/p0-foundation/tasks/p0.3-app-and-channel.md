# P0.3 — Create the Horizon OS app and the `Competition` release channel

**Phase:** P0 · **Est:** 45 min · **Depends on:** P0.1 · **Workstream:** W5
**Gate fed:** G0

## Why this exists
The submission requires the APK on a release channel literally named `Competition`. Creating the channel empty, on Day 1, proves the upload path works before there is anything worth uploading.

## Do this
1. Create a new app in the Meta developer dashboard for Quest (Horizon OS), category and rating placeholder.
2. Set the app's package name/bundle ID and record it — this becomes `Application.identifier` in Unity and cannot be changed later.
3. Create a release channel named exactly `Competition` (case-sensitive).
4. Create a second channel `Internal` for day-to-day test builds so `Competition` stays clean.
5. Upload any throwaway APK to `Competition` to prove the path, then leave it there until P9 replaces it.
6. Record the app ID, package name, and both channel names.

## Done when
- [ ] `Competition` channel exists and has accepted at least one upload
- [ ] Package name recorded and matches the Unity setting
- [ ] `Internal` channel exists separately

## Artefacts produced
- `phases/p0-foundation/accounts.md` updated
- A throwaway APK on the `Competition` channel

## Traps
- Renaming the package later — it is effectively permanent
- Uploading real builds to `Competition` before the freeze, polluting the version list
