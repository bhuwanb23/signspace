# P0.2 — Create the Devpost draft entry and save the submission ID

**Phase:** P0 · **Est:** 20 min · **Depends on:** P0.1 · **Workstream:** W4
**Gate fed:** G0

## Why this exists
The draft locks the entry record early, makes the form's real field list visible (word limits, required uploads), and removes all Day-11 uncertainty about where to submit.

## Do this
1. Open the competition on Devpost and click *Enter a submission* → *Save draft*.
2. Enter the project name **SIGNSPACE** and the current tagline from `docs/06-submission/SUBMISSION-COPY.md`.
3. Screenshot or copy the **full field list** — every required field, every character limit, every upload slot.
4. Write that field list into `docs/06-submission/CHECKLIST.md` as the authoritative form map.
5. Save the submission ID in `phases/p0-foundation/accounts.md`.

## Done when
- [ ] Draft exists and is retrievable
- [ ] The real field list is documented, not assumed
- [ ] Submission ID recorded

## Artefacts produced
- `docs/06-submission/CHECKLIST.md` §1 form map
- `phases/p0-foundation/accounts.md`

## Traps
- Trusting the rules page instead of the actual form — they differ
- Filling the form from memory on Day 11
