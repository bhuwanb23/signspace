# P0.4 — Install the toolchain and get an empty scene onto the headset

**Phase:** P0 · **Est:** 2 h · **Depends on:** P0.3 · **Workstream:** W2
**Gate fed:** G0

## Why this exists
The single most common way to lose two days on a VR project is discovering toolchain mismatches late. Prove the pipeline on an empty scene while your motivation is still high.

## Do this
1. Install Unity 6 LTS — the exact patch listed as supported by Meta XR SDK v207. Record the patch version.
2. Install Android build support (SDK/NDK/OpenJDK) via Unity Hub.
3. Create a new 3D (URP) project at `unity/` and set Build Target to Android.
4. Player settings: IL2CPP, ARM64 only, package name from P0.3, minimum API 32, target API 34, Graphics APIs = Vulkan then GLES3 (or GLES3 only if Vulkan is unstable — record the choice).
5. Import **Meta XR All-in-One SDK v207**. Record the exact package versions resolved.
6. Add the Meta XR rig to the scene, enable hand tracking and passthrough, build, install, run.
7. Record every version in `docs/02-tech/TECH-STACK.md` §1, replacing the `[VERIFY]` tags.

## Done when
- [ ] A build installs and runs on a Quest 3S
- [ ] Hands and passthrough are visible in an empty scene
- [ ] No `[VERIFY]` remains untagged in the tech stack table

## Artefacts produced
- `unity/` project committed
- `docs/02-tech/TECH-STACK.md` version table filled
- `phases/p0-foundation/toolchain.md` with exact versions

## Traps
- Mixing SDK versions across Core/Interaction/MRUK
- Skipping the empty-scene test and importing content first
- Not recording the Unity patch — it will bite during an SDK upgrade
