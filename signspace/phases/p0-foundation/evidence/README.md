# evidence/

Proof for the gates. Every file here backs a checkbox in a `gate.md`.

## Naming

```
p<phase>.<task>-<what>-<YYYY-MM-DD>.<ext>

p0.1-start-status-2026-11-07.png
p0.3-competition-channel-2026-11-07.png
p0.5-invite-flow-step3-2026-11-07.png
```

## Rules

1. **Redact before committing.** Email addresses are fine. Phone numbers, home addresses, 2FA screens and payment details are not.
2. **Never store credentials here** — no passwords, no recovery codes, no keystore files. A screenshot of a password manager is not evidence, it is a liability.
3. **One file, one claim.** If a screenshot proves two things, name it after the stronger claim.
4. **Referenced from the gate.** Every file must be named in the `gate.md` evidence field, or it doesn't count.
