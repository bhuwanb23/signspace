```bash
python signspace/scripts/freeze_check.py        # 16 rows, exit 1 on any FAIL
```

It checks the APK's bytes against `apk-hash.txt`, the version constants, the tag, commits after the
frozen-at timestamp, whether the tree is clean, the archive contents, the submission record, and whether a
video master exists. Account-side rows are printed **NOT RUN** — it will not infer a channel listing from
a file.

**Result of the first run: 4 PASS, 9 FAIL, 3 NOT RUN.** The four passes are the important ones: the
artifact is byte-identical to the freeze record, so nothing has been rebuilt. The nine failures are
paperwork and one missing asset, and the log lists the eight-step remediation in the order it must happen.

**The finding that was not on the checklist:** `P9Checks.ReadCommitHash()` looks for `.git` inside
`unity/`, so the freeze record was written with an empty commit field. That is why the record cannot name
its own source.
