# P8.2 — Run the sessions without helping

**Phase:** P8 · **Est:** 2 h · **Depends on:** P8.1 · **Workstream:** W1
**Gate fed:** G8

## Why this exists
The value of a playtest is proportional to how quiet the tester is left. Every intervention destroys a data point.

## Do this
1. For each tester: cold launch, then hands off. Say nothing except to prevent injury or confusion about hardware.
2. Record: passthrough view, hand footage, and audio.
3. Note the time to first grab, first lock, first near-miss, and the point they stop moving.
4. If they stop for more than 10 seconds, note it as friction and still say nothing.
5. Afterwards, ask three questions: what did you think it was? what did it tell you when you were wrong? would you come back?

## Done when
- [ ] Three recorded sessions
- [ ] Time-to-first-lock measured for each
- [ ] The answers to the three questions captured

## Artefacts produced
- `assets/raw/playtest/*.mp4`
- `phases/p8-playtest/notes-<date>.md`

## Traps
- Explaining 'you have to pinch it' — that sentence is the bug you're looking for
