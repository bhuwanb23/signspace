# P6.3 — The eyes-only path

**Phase:** P6 · **Est:** 1 h · **Depends on:** P6.1 · **Workstream:** W1
**Gate fed:** G6

## Why this exists
A user with limited hand mobility should be able to complete the whole loop with gaze alone. It is also the strongest single accessibility demonstration we can put in a video.

## Do this
1. Define the complete loop in gaze terms: select a shape, inspect fingers, confirm, return to shelf.
2. Make dwell the primary confirm in this mode, with a longer, clearly animated dwell ring.
3. Lengthen the hold requirement so accidental dwells can't lock a shape.
4. Play the whole loop through with your hands in your lap and record it end to end.

## Done when
- [x] Every **control** is dwell-reachable; the lock is a handshape and stays physical — see `docs/03-content/ACCESSIBILITY.md` §5
- [ ] Recorded end to end — **NOT RUN** (H17)
- [ ] No accidental locks in a 5-minute session — **NOT RUN** (H18); structurally impossible for gaze to lock
