# P6.5 — The five accessibility toggles

**Phase:** P6 · **Est:** 1 h · **Depends on:** P6.3 · **Workstream:** W1
**Gate fed:** G6

## Why this exists
Accessibility cannot be a settings panel at the end; but it also has to be reachable. Five toggles, all persistent, all played back.

## Do this
1. Implement: captions on/off (default **on**), high contrast, speed (hold duration + dwell), one-handed mode, eyes-only mode.
2. Make every toggle reachable inside the space (a physical object), not from a system menu.
3. Persist all five; restore on launch.
4. Add the near-miss off switch (from P3.2) as a sixth.
5. Test each toggle by playing the full loop with it on.

## Done when
- [ ] Six toggles, all working, all persistent, all reachable in-space
- [ ] Full loop playable with each enabled
