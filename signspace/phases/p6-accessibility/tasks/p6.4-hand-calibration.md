# P6.4 — 30-second calibration that normalises to the user's hand

**Phase:** P6 · **Est:** 1.5 h · **Depends on:** P2.2 · **Workstream:** W1
**Gate fed:** G6

## Why this exists
Every prior system compares the user to a canonical model and fails if they aren't canonical. We invert that: the reference adapts to their range (N5). It is also the most defensible Best Accessibility Forward argument available.

## Do this
1. Add a calibration flow: open hand, closed fist, thumb-to-each-fingertip. ~30 s, skippable.
2. Record the user's min/max per joint and store it with the save file.
3. Normalise incoming angles into the user's own range before matching, and re-normalise the target too.
4. Test with a deliberately restricted hand (tape two fingers together, or just hold them rigid) and confirm a shape can still lock.
5. Confirm the calibration persists and can be re-run.

## Done when
- [ ] Restricted-range hand can still lock a shape
- [ ] Calibration persists across sessions
- [ ] Skippable without breaking the default path
