# P2.2 — Build the matcher: relative-angle distance with per-joint weights

**Phase:** P2 · **Est:** 2.5 h · **Depends on:** P2.1 · **Workstream:** W2
**Gate fed:** G2

## Why this exists
The matcher decides whether the app feels like a mirror or a bouncer. It is the highest-consequence arithmetic in the build.

## Do this
1. For each of the 26 joints compute the bone-local delta angle between the current pose and the target: `θ_j = 2·acos(|w|)` of the relative quaternion.
2. Apply per-joint weights: proximal joints (wrist, CMC) low (~0.4), mid-phalangeal high (~1.0). Store weights in a serialisable asset so they can be tuned without recompiling.
3. Compute weighted mean angle `D` in degrees across the fingers of interest.
4. Expose `D` live in the Immersive Debugger overlay, plus per-joint contributions for the three worst joints.
5. Verify against the three fixture poses: holding a fixture with your own hand should give a visibly lower `D` than a wrong shape.

## Done when
- [x] A live, per-frame distance value in degrees — `Matcher.DistanceDegrees`, recomputed every `Tick`
- [x] Per-joint weights data-driven, not hardcoded — `Matching/Weights.asset` (`JointWeights`, named
      entries), assignable in the inspector, regenerable from defaults via `SIGNSPACE/P2.2 Write
      weights asset from defaults`; the Python tuner reads the *same* file
- [x] Debug overlay showing the three worst joints — name, angle and weight, worst first
- [ ] **Step 5 on the device**: own hand on a fixture gives a visibly lower `D` than a wrong shape
      (procedure in `matcher-tuning.md` §8; needs the headset, cannot be done in this sandbox)

## Notes against the spec
- Steps 1–4 are done as written, with one deviation forced by measurement: step 3's "weighted mean
  across the fingers" is a weighted mean **within** each finger and a **max across** them. A flat mean
  collapses the nearest intended pair (U-V) from 26.0° to 5.3° — the trap the phase warns about. The
  flat value is still computed and shown, labelled, so the difference stays visible.
- Evidence: same shapes, same 2°/joint noise model, separability **3.89** vs the previous **3.06**.

## Traps
- Averaging all 26 joints equally — the little finger then cancels out the thumb
- Normalising by joint count instead of by total weight, which hides which fingers are wrong
