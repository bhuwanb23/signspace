# P2.7 — Left-hand support, or an explicit decision not to

**Phase:** P2 · **Est:** 1.5 h · **Depends on:** P2.4 · **Workstream:** W2
**Gate fed:** G2

## Why this exists
Left-handers are a third of the population and one-handed play is part of the accessibility story. But mirrored poses are not always valid, and half-support is worse than none.

## Do this
1. Mirror the three fixtures: negate the X axis of each relative quaternion and swap handedness.
2. Test whether mirrored poses lock correctly with the left hand.
3. If yes: enable left hand, and add a handedness toggle in the debug overlay.
4. If no: disable left hand cleanly, show a one-line explanation, and log it as a known limitation for the honest mirror.
5. Record the decision and the reason in `docs/04-design/UX-STATES.md`.

## Done when
- [ ] A definite answer, tested, with the evidence
- [ ] No half-broken left-hand path left in the build
