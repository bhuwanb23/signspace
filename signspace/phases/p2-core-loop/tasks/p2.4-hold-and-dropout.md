# P2.4 — The 0.7 s hold, with dropout tolerance

**Phase:** P2 · **Est:** 1 h · **Depends on:** P2.3 · **Workstream:** W2
**Gate fed:** G2

## Why this exists
A shape must be *held*, not touched. And a half-second tracking dropout must never reset a nearly-successful attempt — that single behaviour is what makes hand tracking feel broken in most apps.

## Do this
1. Implement a hold timer that only accumulates while `D` is inside the locked band.
2. Add a dropout grace of 200 ms: if tracking confidence dips, freeze the timer rather than reset it.
3. On lock, fire the lock event once and latch until the hand leaves the band for >500 ms.
4. Test: 20 locks, then 20 deliberate flicks in and out of the band to confirm no false locks.
5. Log every lock with a timestamp to `phases/p2-core-loop/lock-log.csv`.

## Done when
- [ ] 20/20 intentional locks — **20/20 in simulation** (`hold_sim.py`, each attempt with a 0.5 s dropout
      injected); device run open
- [ ] 0/20 false locks from flicks — **0/20 in simulation** (worst flick 0.62 s in-band against a 0.70 s
      requirement); device run open
- [x] Hold timer visibly correct in the debug overlay — `Holding / Coasting / Stalled / Locked` plus
      banked seconds and live progress
