# P5.6 — Select the final shipped set from the trackability data

**Phase:** P5 · **Est:** 1 h · **Depends on:** P5.4 · **Workstream:** W3
**Gate fed:** G5

## Why this exists
The set must be chosen by evidence, not by ambition. The product is allowed to shrink; it is not allowed to include a shape that fails.

## Do this
1. Join the trackability table (P1.5) with the captured poses (P5.4).
2. Any shape below ~70% lock rate in normal light is removed from the set and moved to the honest mirror.
3. Recheck that the near-miss pairs survive the cut — if the cut breaks a pair, note which demo is lost.
4. If fewer than 8 shapes survive, fall back to 6 shapes / 1 family and say so in the description.
5. Update `SIGNSET.md` §2–5 and the near-miss pair table to match reality.

## Done when
- [ ] Final set decided with a documented reason per exclusion
- [ ] Near-miss pairs re-verified after the cut
- [ ] Document matches the build
