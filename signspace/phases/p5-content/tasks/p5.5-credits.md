# P5.5 — Put the signer in the product, not in the small print

**Phase:** P5 · **Est:** 1 h · **Depends on:** P5.3 · **Workstream:** W4
**Gate fed:** G5

## Why this exists
Credit is not a compliance artefact. A Deaf signer's hand is the product's content, and the product should say so where the user can see it.

## Do this
1. Add a credits object on the shelf that, when touched, shows the signer's name, city, and the date of capture.
2. Include the line: *'This is practice software, not a replacement for a Deaf teacher.'*
3. Show it within the first minute of first launch — not buried in a menu.
4. Confirm the wording with the signer before shipping.

## Done when
- [ ] Credits reachable in the first minute
- [ ] Wording approved by the signer
- [ ] The 'not a replacement' line present

## Artefacts produced
- `unity/Assets/_Project/Prefabs/Credits.prefab`

## Traps
- Putting credits in a settings menu — hidden credit is no credit
