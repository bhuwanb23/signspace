# P5.2 — Write the capture protocol before the session

**Phase:** P5 · **Est:** 1.5 h · **Depends on:** P5.1 · **Workstream:** W3
**Gate fed:** G5

## Why this exists
A capture session that has to be repeated costs a week we don't have. The protocol is what makes one session enough.

## Do this
1. Write the printable one-pager the signer will see: the 12 shapes, the order, how long, what to do between takes.
2. Specify equipment: two cameras (front and 30° side), even lighting, plain background, no rings or reflective jewellery.
3. Define takes: per shape, 3 s held, 3 vantage points, plus 2 s of neutral at the start and end.
4. Define the naming convention and the manifest row for each take.
5. Include the blind-spot set (M, N, T, R, S, E) — we need them *correct* for the honest mirror.
6. Include the retake rule: a take is rejected if the hand is out of frame, rotated past 30°, or unlit.

## Done when
- [ ] `docs/03-content/CAPTURE-PROTOCOL.md` complete and printable
- [ ] Naming convention and manifest schema defined
- [ ] Session scheduled to fit in 90 minutes

## Artefacts produced

## Traps
- Over-scoping the session — 90 minutes is the ceiling before hands get tired and data gets worse
