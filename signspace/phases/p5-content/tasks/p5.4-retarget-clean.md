# P5.4 — Retarget and clean the takes into shipped poses

**Phase:** P5 · **Est:** 3 h · **Depends on:** P5.3 · **Workstream:** W2
**Gate fed:** G5

## Why this exists
Raw capture is not a product asset. The retarget step is where a take becomes something the matcher can compare against.

## Do this
1. Import takes, retarget to the 26-joint shipped rig, fix any joint flips by hand.
2. Average 30 frames of the held steady portion of each take to reduce noise.
3. Export to the frozen JSON schema from P2.1; run `scripts/validate_poses.py` on every file.
4. Preview each pose on the reference hand and eyeball against the video take.
5. Store one canonical pose per shape, plus the vantage variants for the honest mirror.

## Done when
- [ ] 12 canonical poses, validated
- [ ] 3 vantage renders per shape available for the mirror
- [ ] No joint flips in preview
