# P5.3 — Run the capture session

**Phase:** P5 · **Est:** 3 h · **Depends on:** P5.2 · **Workstream:** W3
**Gate fed:** G5
**Status:** ⛔ blocked on the signer — session kit ready in [`../session-kit.md`](../session-kit.md)

## Why this exists
This is the only task in the project that depends on another person being present. It happens once.

## Do this
1. Set up and test the rig 30 minutes before the signer arrives.
2. Capture neutral first — every pose is relative to it.
3. Work through the 12 shapes in family order, then the blind-spot set.
4. Review each take on the spot; retake immediately if it fails the retake rule.
5. At the end, play back two takes to the signer and confirm they read as the correct shapes.
6. Record the signer's own description of each shape in their words — this becomes the in-app copy.

## Done when
- [ ] All 12 shapes captured from 3 vantage points *(blocked: needs the signer)*
- [ ] Blind-spot set captured *(blocked)*
- [ ] Signer has confirmed each take reads correctly *(blocked)*
