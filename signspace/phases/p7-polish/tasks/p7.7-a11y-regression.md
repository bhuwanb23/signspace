## Build status (17 Nov 2026)

**The regression pass found a real regression, in the feature rather than the polish.** The **High
contrast** switch reached only the caption panel and the gaze caption. The HUD's own lines, the tray's
plates and labels, and the near-miss copy ignored it — so a user turned it on, saw one panel change, and
concluded the switch was broken. `P7.7` now runs
the entire P6 suite inline (106 assertions) and then asserts what P6 could not see: the tray still
builds eight blocks, the fingertip targets still build, captions still default on, and the calibration
math still turns a half-range hand into a 2× scale.

**High contrast now does something:** HUD text goes pure white, the tray plates go near-black with white
labels, and the near-miss drops its dash and degree number for the plain form ("That's O."). It is a
palette swap, not a post effect, because a filter would also change the passthrough the user is looking
through.

**NOT RUN:** the eight device recordings. `toggle-matrix.md` is updated with the desk column and keeps
every device row NOT RUN. `HUMAN-TASKS` H14–H22.
