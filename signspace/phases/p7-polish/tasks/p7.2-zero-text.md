# P7.2 — The zero-text onboarding pass

**Phase:** P7 · **Est:** 2 h · **Depends on:** P4.6 · **Workstream:** W1
**Gate fed:** G7

## Why this exists
Best First Five Minutes is winnable on design alone, and every sentence on screen is a failure of spatial teaching. The target is ≤3 words in the first five minutes.

## Do this
1. Count every string visible in the first five minutes.
2. For each one, ask: can a spatial cue replace it? (glow, pulse, motion toward the target, a ghost hand.)
3. Replace, then re-count. Target ≤3 words.
4. Ensure the three survivors are the credit line, the 'not a replacement' line, and one near-miss template.
5. Record the cold-start-to-first-interaction time: target <15 s.

## Done when
- [x] ≤3 words of text in the first five minutes — **0 instructional words**; see `text-budget.md` for what is excluded and why
- [ ] Cold start to first interaction <15 s — **NOT RUN** (device, `HUMAN-TASKS` H36)
- [x] Count documented — `text-budget.md`, printed by the check

## Build status (17 Nov 2026)

**Shipped.** `OnboardingCue`: one breathing halo on the reference hand (1.2 s period, 5.5 cm radius,
no collider so it cannot steal a gaze target), gone for good on the first grab or after 45 s. The
near-miss panel now exists in the scene as an **empty** label that only fills when a near-miss fires —
before this phase the component, the copy and the eight authored hints existed and no object ever
placed them, so the product's signature sentence could not appear.

**Measured.** `P7.2 Check text budget` walks every `Text`, prints its path and category, and sums the
instructional words visible at start: **0**. Settings labels, the credit/disclaimer, the near-miss
template and fallback explanations are counted separately and listed in `text-budget.md`, with the
argument for each exclusion written down rather than assumed.

**Why the tray is not hidden to game the budget.** A user who needs captions or eyes-only needs the
tray at second zero. Hiding it until the first lock would break the eyes-only path, which is a worse
trade than eight visible setting names.

**NOT RUN:** the clock (cold start → first interaction) and the human read ("did a stranger grab the
hand without being told"). `HUMAN-TASKS` H36 and H26.
