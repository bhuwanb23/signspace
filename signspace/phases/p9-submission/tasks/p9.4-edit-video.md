# P9.4 — Edit to under three minutes

**Phase:** P9 · **Est:** 2.5 h · **Depends on:** P9.3 · **Workstream:** W4
**Gate fed:** G9

## Why this exists
The edit is where 25% of the score is lost or won. Hands-first by 0:30 is a hard requirement, not a preference.

## Do this
1. Assemble to the storyboard timecodes. Cut anything that doesn't evidence a rubric claim.
2. Verify: duration <3:00, hands-first visible by 0:30, no fake UI, no motion smoothing that hides frame rate.
3. Add captions or on-screen text; avoid narration if the visuals carry it.
4. Design the thumbnail and first frame — the first frame is the near-miss line.
5. Export at the platform's recommended settings; check file size against Devpost limits.

## Done when
- [ ] Final cut <3:00
- [ ] Hands-first by 0:30
- [ ] Plays correctly in an incognito browser

## Traps
- Letting the edit creep past 3:00 — cut the second-best shot, not the evidence
