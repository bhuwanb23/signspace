# P9.1 — Freeze the build

**Phase:** P9 · **Est:** 1 h · **Depends on:** P8 · **Workstream:** W5
**Gate fed:** G9

## Why this exists
The last commit before submission is the most dangerous object in the project. Freezing makes it deliberate.

## Do this
1. Bump the version to `1.0.0-competition`.
2. Confirm keystore is correct and stored somewhere recoverable; confirm IL2CPP + ARM64.
3. Build a release APK; record its SHA-256 hash and size.
4. Install that exact APK on both devices and run the full loop once.
5. Tag the commit `v1.0-competition` and push.

## Done when
- [ ] APK hash recorded
- [ ] Installs and plays on both devices
- [ ] Commit tagged

## Artefacts produced
- `phases/p9-submission/BUILD.md` with the hash
- git tag `v1.0-competition`

## Traps
- Rebuilding after this point — if you must, you re-run P9.1 in full
