# P9.5 — Verify every string against its limit

**Phase:** P9 · **Est:** 45 min · **Depends on:** P9.4 · **Workstream:** W4
**Gate fed:** G9

## Why this exists
Character limits are checked by script, not by eye. A truncated tagline is a self-inflicted wound on the first thing a judge reads.

## Do this
1. Run `python3 scripts/count.py` and confirm the tagline ≤140 and description ≤500.
2. Re-read the description against `COMPETITION-FIT.md` — remove any claim not evidenced in the build or video.
3. Confirm the anti-claim paragraph is present and still accurate.
4. Confirm the tagline's promise matches the video's first 10 seconds.

## Done when
- [ ] Both limits pass by script
- [ ] Every claim evidenced
- [ ] Anti-claim present and accurate

## Artefacts produced
- `docs/06-submission/SUBMISSION-COPY.md` final
- `phases/p9-submission/count-output.txt`

## Traps
- Editing the description after running the count and not re-running it
