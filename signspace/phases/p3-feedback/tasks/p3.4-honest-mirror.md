# P3.4 — Build the honest mirror: publish the shapes we can't see

**Phase:** P3 · **Est:** 1.5 h · **Depends on:** P1.5 · **Workstream:** W3
**Gate fed:** G3

## Why this exists
No competition entry admits its platform's limits. Ours does, visibly, with the reasons — which builds trust with a Deaf judge, signals engineering depth, and flatters Meta's roadmap (see N2).

## Do this
1. Take the 'Never' and 'Low' rows from `TRACKABILITY.md` (expected: M, N, T, R, and possibly S, E).
2. Build a panel: each excluded shape shown correctly (from the signer capture), greyed, with one line of why.
3. Include the count line: *'X of Y handshape variants are robustly trackable today.'* — with real numbers from P1.5.
4. Reach it from the shelf (a physical object that opens it), not from a settings menu.
5. Run it past the signer if possible — the shapes must be shown *correctly* even though they're excluded.

## Done when
- [x] Panel ships with correct shape renders — the four excluded shapes (M, N, R, T) are the real
      `Probe/<id>.json` captures, built by the same `HandVisual`/`ApplyPose` as the taught set, grey
      unlit, drawn at 0.85. `validate_poses.py`: 28 shapes, 0 problems. *(handshape correctness still
      wants a signer's eye — see below)*
- [x] Count line is driven by the data, and cannot claim tracking it has not measured — the two forms
      are in §4.2; `measured:false` means the shipped line says what is out of the build and the dated
      line stays unreachable
- [x] Reachable from within the space, not a menu — `UI/PanelOpener.cs` on a plinth at (0, 0.62, 0.90);
      pinch inside 12 cm. P4 re-homes that object onto the shelf
- [~] Run it past the signer — not possible this week; the requirement is recorded as an open criterion
      rather than assumed
- [~] Count line uses measured numbers — it will, from the same file, the moment `measured` flips
      (P3.6). Shipping an unmeasured number was the alternative and it was refused

## What was decided, and what it cost

| Decision | Why |
|---|---|
| The excluded set is **M, N, R, T** — not "M, N, T, R, possibly S, E" | S and E resolve (`may-resolve`), and **F was demoted** out of `not-resolvable`: the contact survives with fewer fingers. The four that remain are the ones whose failure is structural, not optical |
| **One line per shape, from the file's `note`** — the per-category copy was dropped | a category sentence is a general statement; the panel exists to replace general statements with specifics |
| The unmeasured line says *"stay out of this build"*, not *"trackable"* | "trackable" is a tracking claim; there is no tracking behind it yet |
| `measured` lives in the data file, not in the code | a flag in code gets flipped by whoever is in a hurry; a flag in the file P3.6 edits gets flipped by the measurement |
| The panel is **closed at rest**, opened by pinching an object | it is something you find, not a settings screen and not a startup card |
| Hands are parented **beside** the canvas, not under it | `HandVisual` builds in metres; the canvas scale (0.0007) would shrink a hand to nothing |
