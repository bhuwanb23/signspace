# P3.2 — Confidence gating: silence is the default

**Phase:** P3 · **Est:** 1.5 h · **Depends on:** P3.1 · **Workstream:** W2
**Gate fed:** G3

## Why this exists
A wrong diagnosis is worse than no diagnosis — it teaches a false correction to someone learning a language. The gate that prevents it is the difference between a delightful feature and a harmful one.

## Do this
1. Pull hand-tracking confidence per frame; define a floor (start at 0.7, tune).
2. Near-miss may only fire if confidence stayed above the floor for the preceding 400 ms.
3. Add a per-session cap: no more than one near-miss per 20 s, so it never becomes nagging.
4. Add an easy off switch in the accessibility toggles (P6.5).
5. Run a 20-attempt false-positive test with fast, sloppy, wrong-but-not-close hands. Target: **zero** fires.

## Done when
- [ ] Zero false positives over 20 sloppy attempts
- [ ] A visible confidence floor value in debug
- [ ] Session rate cap working

## Traps
- Firing on the first frame that satisfies the rule — require a stable window
