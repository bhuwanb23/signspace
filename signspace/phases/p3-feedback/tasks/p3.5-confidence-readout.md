# P3.5 — Live confidence readout that pauses instead of failing

**Phase:** P3 · **Est:** 1 h · **Depends on:** P3.2 · **Workstream:** W2
**Gate fed:** G3

## Why this exists
When tracking degrades the app must visibly stop measuring, not quietly mis-measure. This is the behaviour that makes the fragility honest instead of confusing.

## Do this
1. Add a subtle indicator that dims when confidence is below the floor.
2. Freeze the hold timer, dim the match display, and show *'watching'* state (no words if possible — a visual pulse).
3. Resume automatically when confidence returns.
4. Test by occluding a hand behind the other, moving fast, and leaving the room's lights low.
5. Confirm no lock can ever be awarded while confidence is below the floor.

## Done when
- [ ] Pause behaviour proven in three degradation scenarios
- [ ] No lock awarded below the floor
- [ ] No error string anywhere

## Artefacts produced
- `unity/Assets/_Project/Scripts/UI/TrackingConfidence.cs`

## Traps
- Showing a score during a pause — a frozen number reads as a stalled app
