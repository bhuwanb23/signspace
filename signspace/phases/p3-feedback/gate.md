# GATE G3 — Does the near-miss land in under 30 seconds of play — and does it never once lie?

**Phase:** P3 · **Verdict:** ⬜ not yet evaluated

## Criteria — all must be true
- [ ] All **4** near-miss pairs in the shipped six-shape set fire correctly — B↔U, U↔V, V↔W, C↔O
      (`SIGNSET.md` §5 lists 8, but A↔O, I↔Y, L↔Y and D↔F need shapes not in the six; they belong to
      the 12-shape build in P5. Only U↔V is inside the 26° confusion window — the others fire at large
      separation, so they prove the naming rule, not the confusion case)
- [ ] Zero false positives across 20 sloppy attempts
- [ ] Confidence gate, session rate cap, and an off switch all working
- [ ] Near-miss copy is ≤12 words and understood by a non-signer in one read
- [ ] Honest-mirror panel ships, reachable from inside the space, with correct (not shortcut) shape renders
- [ ] The published count matches measured data and carries a measurement date
- [ ] No lock can be awarded while confidence is below the floor
- [ ] **A stranger playing for 30 seconds experiences the near-miss and can explain what it told them**

## If red
If the near-miss lies even once, disable it rather than tune it live — a silent product is acceptable, a wrong one is not. If the honest mirror reads as an apology rather than a flex, rewrite the framing before moving on: the panel is a never-cut item, so a G3 red blocks P4.
